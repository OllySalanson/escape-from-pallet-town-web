# The playtest kit

What the explorer run carries so every harbour game can be tried the night it
lands (`src/game/dev/playtestKit.ts`), and the PLAYTEST BOARD by the landing
(`src/game/dev/playtestBoard.ts`). Made by `tools/playtest/playtestKit.mjs`
against a test-mode build at the 3x window.

- `02-board.png` - the board, read from the path two steps from the landing.
- `03-game-corner.png` - GO TO A ROOM: straight into THE GAME CORNER.
- `04-who-jumps.png` - PLAY: POKéMON JUMP opened from the board, with the kit's
  jumpers of every jump type (before the kit: "Nobody here can jump").
- `05-first-go.png` - the first go pays tickets.
- `06-day.png`, `06-night.png` - THE HOUR set by hand, whatever the clock says.
- `08-paid-again.png` - NEW DAY: the same cabinet pays a second time.
- `09-the-cove.png` - GO TO THE HARBOUR: put down in THE COVE.
