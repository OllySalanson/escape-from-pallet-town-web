# The rim says the hunters are a pack

The final check over the pit at THE RAID ARENA, before and after the hunter line
says that a raid alone is hunted by one hunter to every district, with the
raid's own rival keeping the landing.

- `before.png`: `Hunter  LT. SURGE: ...`, one name, when KOGA might be the one who catches you two districts on.
- `after.png`: `Hunters  one a district, LT. SURGE where you land: ...`

Made with `node tools/playtest/characters3Fixes.mjs "http://localhost:<port>/?testmode=1" <out> --only=walk`
against the dev server (1200x768). The before was taken with the pack wording
switched off, which renders exactly as `main` does.
