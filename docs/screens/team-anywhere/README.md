# YOUR TEAM and the one box picker

P anywhere in the harbour picks the next raid's team from every box (`scenes/TeamScene.ts`), and every picker of your Pokémon lists from `ui/boxPicker.ts`: every box, best fits first, the box named on each row, a find over it.
Made by `tools/playtest/teamAnywhere.mjs` on a test-mode build at 1280x800.

- `01-jump-boxes.png` - POKéMON JUMP lists every box, jumpers first, each row naming its box.
- `03-team.png` - P in the Game Corner: the next raid's team, then everybody in the boxes.
- `04-team-find.png` - FIND "box 2" leaves only what lives in Box 2.
- `05-team-taken.png` - the Mankey from Box 2 taken onto the team, which is the bench the hall opens on.
- `07-team-in-hall.png` - in THE RAID ARENA's hall the bench holds the team chosen in the arcade.
- `08-day-care.png` - the Day-Care Man's list names every row's box, those he takes first.
