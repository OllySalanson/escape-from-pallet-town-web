# The 2 OUT plaque is gone

The captain, 26 Nov 2026, of the plaque on THE RAID ARENA's red runner: "I have
no idea what two out means... I don't think it should be there." It was a count
of raids in a row that got out alive, chalked from the second, struck through
when a raid was lost. It bought nothing and nobody could read it at a glance,
so it went, with the save's count behind it.
