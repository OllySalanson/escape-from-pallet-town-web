# Room for a catch

The rim, with a Satchel packed with ten Poké Balls: the pack carries the Balls out and has no four free squares for what they catch. Before, nothing said so until "No room in the pack!" in the fight; after, the rim's foot says it. Made on a test-mode build, `?testmode=1`, through `tools/playtest/ai-player/act` from a save whose last pack was ten Balls.
