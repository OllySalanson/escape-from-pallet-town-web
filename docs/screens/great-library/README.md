# THE GREAT LIBRARY

Photographed by `tools/playtest/greatLibrary.mjs` against a test-mode build
(`VITE_EPTW_TEST_MODE=pixels`) in the real 1200x768 window, in this machine's
own headless browser:

```bash
node tools/playtest/greatLibrary.mjs <cdp port> <build url> <out dir>             # a new game
node tools/playtest/greatLibrary.mjs <cdp port> <build url> <out dir> --explorer  # the explorer run
```

- `outside.png` - the library at the top of THE GREEN, set back into the trees
  beside the boutique, its name over its roof.
- `library.png` - inside: the bookcases and back windows, the stacks, the
  librarian at her desk, THE BOLTHOLE open on its lectern and the golden plinth
  on the runner.
- `golden-plinth-locked.png` - in a normal game the golden book is chained shut,
  and facing it says so; it does not open.
- `book-open.png` - THE BOLTHOLE full screen, on its wooden plinth.
- `page-turning-1.png`, `page-turning-2.png` - a page lifting at the spine and
  coming down on the far side, a frame apart.
- `vale-secrets-open.png`, `vale-secrets-spread.png` - in the explorer run the
  golden book opens, on its golden plinth, a page per secret.
