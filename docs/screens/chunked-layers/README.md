# Greystone Vale's tile layers, chunked

The same view of Millbrook on a test-mode build (`?testmode=pixels`, 1200x768), before (`main`) and after the layers were made in 64-tile chunks (`world/layerChunks.ts`). The tile art is the same pixel for pixel. What differs is what a raid places at random: a stake marker, a bird, and the chip's words.
