# A trainer asks in their own words

Spoken to, a trainer used to answer with a stat card and a rule: "SCOUT TAM:
2 Pokémon, lead Lv 3 to your Lv 12. A trainer battle cannot be fled."
MILLBROOK's night critic (26 Nov 2026) marked it as a line FireRed never
shows. The question is now the trainer's own first spoken line, with the same
CHALLENGE / BACK AWAY choice still starting on BACK AWAY; CHALLENGE goes into
the fight, which opens on FireRed's "SCOUT TAM would like to battle!", and
BACK AWAY just closes the box.

`before/` is the critic's picture on `main` at `fb101e46`; `after/` is this
change, played with `tools/playtest/ai-player/act` on a test-mode build from a
raid stood at Mill Square (`tools/playtest/standRaid.mjs`).
