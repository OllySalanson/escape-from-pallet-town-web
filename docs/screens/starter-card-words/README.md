# Bulbasaur's starter card in plain words

Oak's table card said Bulbasaur has "Strong special bulk". 'Bulk' is a word only players of the games know, and beside Squirtle's "Best physical defense" it read as a different kind of claim. It now says "Best special defense", which is true: base Sp. Def 65, against Squirtle's 64 and Charmander's 50.

- `after.png`: after the change.
