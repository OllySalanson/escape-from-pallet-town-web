# The chevron shows the key that moves you

The critic's review, problem 12: "Twice the arrow walked me into the scenery, because the road jogs a tile and the chevron points at somewhere further down it." The chevron aimed at wherever the walk had got to eight steps on and pointed the larger way to it, so where the road jogged it named a key into a bank, a tree or, here, the Onix guarding a cache.

Now it shows the straight run the walk sets off on: the first step that shortens the walk, carried on while it still does. Of two equally good first steps, the way the player already faces wins, so a held key keeps going until the road turns.

- `before.png` - one step off THE QUARRY landing (184,80) with a Sealed dispatch to the south: the chevron says LEFT, into the Onix.
- `after.png` - the same tile: DOWN, to the ledge, which is the walk.

Measured by holding whatever key the chevron showed from THE QUARRY landing to the end of a raid (a stepped driver, wild rolls off, 400 ms a press so a turn on the spot is not counted): 17 presses into something on main, 1 with this change (the other stop was a trainer's watch, the same in both runs).

Made on `?testmode=pixels` at 800x512: deploy with `--insertion=greystone-vale-the-quarry --level=40`, walk to (184,80), and draw the arrow as a first raid draws it (`plan.stagedChase`), because a later raid shows it only in the last thirty seconds.
