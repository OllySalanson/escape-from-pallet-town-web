# The defeat sequence

Frames of what a lost raid opens on, before the result screen's accounting.
Captured from the running game at 1000x760 in headless Chrome.

| file | beat |
| --- | --- |
| `1-line-up.png` | The held instant before the first beat: the party as deployed, the player beside them, name plates on the ground. Squirtle is drawn larger because it was the one still standing when the party ran out. |
| `2-fall.png` | Beat one. Everyone goes down together; only the player keeps their colours. |
| `3-stripped.png` | Beat two. What was lifted off you is stamped TAKEN and dulled, and stays on screen so it can be compared. |
| `4-secure-slot-held.png` | Beat three. What the secure slot held stands back up in full colour. |
| `5-result-screen.png` | The unchanged result screen from #71, which the sequence hands over to. |

Frames 1, 2 and 5 are a real lost raid played end to end. Frames 3 and 4 are the
same page and the same stylesheet with the beat states set directly, because a
355ms screenshot cannot be aimed at a 1.3s beat reliably.
